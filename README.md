# VÉRTIGO! — Prototipo demostrativo

Este proyecto es únicamente una **muestra visual e interactiva** de una propuesta de interfaz para la gestión de un gimnasio. Está basado en pantallas de diseño y utiliza datos de ejemplo.

> **Importante:** no es un sistema funcional ni está listo para usarse en operaciones reales. No tiene conexión con un servidor o una base de datos. Los accesos, formularios, cifras y acciones que aparecen en pantalla son demostrativos; no validan usuarios reales ni guardan información de forma persistente.

## Ver el prototipo

Puedes probarlo en GitHub Pages: [https://angelvitalmx.github.io/vertigo-prototipo/](https://angelvitalmx.github.io/vertigo-prototipo/)

Abre `index.html` en un navegador. No se requiere instalación ni compilación. La tipografía se carga desde Google Fonts, por lo que se necesita conexión a Internet para verla correctamente; sin conexión, se usarán fuentes alternativas.

## Archivos

- `index.html`: página de entrada del prototipo.
- `css/styles.css`: estilos y presentación visual.
- `js/app.js`: pantallas, datos de muestra e interacciones de demostración.

## Alcance

El prototipo sirve para explorar la apariencia y algunos flujos de navegación. No debe utilizarse para administrar socios, pagos, accesos, membresías ni información personal. Para convertirlo en un sistema operativo sería necesario implementar, entre otros elementos, servicios de backend, almacenamiento persistente, autenticación y validaciones reales.
